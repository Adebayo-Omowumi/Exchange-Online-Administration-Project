# Runbooks

# create-shared-mailbox.md

# Objective

Create a shared mailbox in Exchange Online.

# Steps

1. Open Exchange Admin Center

2. Navigate to Recipients > Mailboxes > Shared

3. Select Add Shared Mailbox

4. Enter mailbox name and email address

5. Create mailbox

6. Assign Full Access permissions

7. Assign Send As permissions

8. Test mailbox access



# Validation

Mailbox visible in Outlook

Send As working correctly

Users can open mailbox
